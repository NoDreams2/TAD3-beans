# Практическая работа 3. Инженерия машинного обучения

Версионирование данных и моделей, автоматический ML-пайплайн и эксперименты
с помощью **Git + DVC**. Удалённое хранилище данных и моделей — **DagsHub**.

**Выполнил:** Н. Е. Лукьянов, группа КИ23-16/1Б

## Задача

Классификация болезней листьев фасоли по фотографии, 3 класса:

| Класс | Что это |
|---|---|
| `angular_leaf_spot` | угловая пятнистость листьев |
| `bean_rust` | ржавчина фасоли |
| `healthy` | здоровый лист |

Датасет **Beans** (лаборатория ИИ Университета Макерере, лицензия MIT):
https://huggingface.co/datasets/AI-Lab-Makerere/beans

| Часть | Фото | Для чего |
|---|---:|---|
| train | 1 034 | обучение |
| validation | 133 | проверка после каждой эпохи, выбор лучшей эпохи |
| test | 128 | итоговая оценка, модели её не видят |

Версия датасета зафиксирована в `params.yaml` (`data.revision`), поэтому
данные у всех одинаковые.

## Пайплайн

Описан в `dvc.yaml`, запускается одной командой `dvc repro`.
Схему стадий показывает команда `dvc dag`.

```
download → prepare → augment → train@simplecnn ┐
                         │      train@resnet18  ├→ evaluate
                         └────→ train@mobilenet_v3 ┘
```

| Стадия | Скрипт | Что делает | Результат |
|---|---|---|---|
| download | `src/download.py` | скачивает датасет с Hugging Face | `data/raw/` |
| prepare | `src/prepare.py` | приводит фото к размеру 224×224 | `data/processed/` |
| augment | `src/augment.py` | делает новые фото из обучающих (поворот, отражение, обрезка, яркость, контраст) | `data/augmented/`, `reports/augment_examples.jpg` |
| train@… | `src/train.py` | обучает **все три модели** за один запуск, сохраняет лучшую эпоху | `models/*.pt`, `metrics/train/*.json`, `plots/train/*.csv` |
| evaluate | `src/evaluate.py` | оценивает модели на тестовой части | `metrics/test.json`, `plots/confusion/`, `reports/summary.md` |

DVC запоминает хеши входов и выходов каждой стадии в `dvc.lock`. При
повторном `dvc repro` пересчитываются только стадии, у которых что-то
изменилось (код, данные или параметры).

## Модели

| Модель | Параметров | Как обучается |
|---|---:|---|
| `simplecnn` | ≈0,24 млн | своя свёрточная сеть, с нуля |
| `resnet18` | ≈11,2 млн | предобучена на ImageNet, дообучается целиком |
| `mobilenet_v3` | ≈1,5 млн | лёгкая сеть MobileNetV3-Small, предобучена на ImageNet |

После каждой эпохи модель проверяется на validation. В `models/` сохраняется
состояние модели на эпохе с наименьшей ошибкой на проверке, кривые обучения
пишутся в `plots/train/`.

## Параметры

Все параметры — в `params.yaml`: размер картинок, настройки аугментации,
использовать ли аугментированные данные (`train.use_augmented`), число эпох
и скорость обучения для каждой модели.

Изменить параметр без правки файла и сразу запустить эксперимент:

```
dvc exp run -S models.resnet18.epochs=15 -S models.resnet18.lr=0.0001
```

## Установка (Windows)

```
python -m venv venv
venv\Scripts\activate
pip install torch==2.14.1 torchvision==0.29.1 --index-url https://download.pytorch.org/whl/cu126
pip install -r requirements.txt
```

Проверка видеокарты: `python -c "import torch; print(torch.cuda.is_available())"` должна вывести `True`.

## Основные команды

| Задача | Команда |
|---|---|
| Запустить весь пайплайн | `dvc repro` |
| Метрики текущей версии | `dvc metrics show` |
| Сравнить с другой версией | `dvc metrics diff v1-original` |
| Графики (откроется HTML) | `dvc plots show` |
| Таблица экспериментов | `dvc exp show` |
| Вернуть эксперимент в рабочую папку | `dvc exp apply <имя>` |
| Перейти к этапу работы | `git checkout v1-original` и затем `dvc checkout` |
| Вернуться к последней версии | `git checkout main` и затем `dvc checkout` |
| Отправить данные и модели в хранилище | `dvc push` |
| Скачать данные и модели без обучения | `dvc pull` |

## Этапы работы (метки в Git)

| Метка | Что сделано |
|---|---|
| `v1-original` | пайплайн, три модели обучены на исходных данных |
| `v2-augmented` | добавлена аугментация, модели обучены на исходных + новых данных |

## Как посмотреть результаты, не запуская обучение

1. `git clone` репозитория — в нём уже есть метрики (`metrics/`), кривые
   обучения (`plots/`) и сводная таблица (`reports/summary.md`).
2. `dvc pull` — скачать из DagsHub данные и обученные модели.
3. `dvc metrics show`, `dvc plots show`, `dvc exp show` — посмотреть результаты.

Или открыть страницу репозитория на DagsHub: там видны файлы данных,
модели и метрики прямо в браузере.
